Hand retargeting · teleoperation · bimanual

Manus Gloves → Two Allegro Hands

Two Manus gloves track the operator's fingers, a learned geometric retargeting network maps each hand's 21 keypoints to the 16 joints of an Allegro Hand V4, and a ROS 2 bridge streams both hands of a dual-arm robot in real time.

Code & setup guide Robot drivers Upstream: GeoRT (Meta / UC Berkeley)

Recorded Manus glove sessions replayed through the trained models. The robot side shows the exact joint angles sent to the hands, rendered in SAPIEN.

Pipeline

01 · gloveManus SDK → ROS 2Left and right C++ clients publish per-joint rotations from both gloves.
02 · keypointsHand FK21 keypoints in a canonical wrist frame, so only finger articulation remains. ZMQ :8765 / :8766.
03 · retargetGeoRT, one model per handTrained without paired data: fingertip direction, Chamfer, curvature and pinch losses. ZMQ :7777 / :7778.
04 · robotROS 2 bridgeJointState to both Allegro drivers, rate-limited and clamped to joint limits.

Results

The mapping is monotonic for every finger. Near full extension there is a dead band: the Allegro keeps about 1 rad of flexion because the model matches fingertip geometry, not joint angles. The left thumb, which needs the most mirroring corrections, is the weakest. These numbers measure consistency with the operator, not task success.

Learned vs rule-based

The repository also contains the earlier pipeline: glove → DexHand gesture model → a fixed DexHand-to-Allegro joint-index table (dex2all). It copies joint angles one-to-one. GeoRT instead learns the mapping from fingertip geometry, which accounts for the Allegro's longer fingers, its different thumb and its joint limits, and has an explicit pinch term.

Try it

git clone https://github.com/ismael-esp/allegro-hand-retargeting.git && cd allegro-hand-retargeting
conda create -n geort python=3.11 -y && conda activate geort
pip install torch && pip install -r requirements.txt && pip install -e .     # sapien==2.2.2, numpy<2
bash scripts/download_data.sh                    # recorded Manus sessions
python scripts/eval_flexion_correlation.py       # reproduces the table
python geort/trainer.py -hand allegro_right -human_data manus_data_right -ckpt_tag my_right
bash scripts/run_dual_teleop.sh                  # gloves → both Allegro hands (robot drivers running)
